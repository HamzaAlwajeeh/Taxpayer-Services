Screen explanation

How the Flutter project is structured and how execution moves through it.

The project starts in main.dart, where services, preferences, notifications, app settings, and Bloc observation are initialized. Shared infrastructure lives in core: API transport, routing, constants, dependency injection, reusable widgets, and local storage. Business work is grouped inside Features, where each domain owns its UI, state logic, data contracts, repositories, and models. The login path shows that structure in action: the form validates input, the Cubit emits states, the repository calls the API, Dio sends the request, and SharedPreferences stores the token for later authenticated requests.
